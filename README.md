# Interactive Counter

A simple browser-based interactive counter for CMPM 121 S01.

## Controls

- **Click Me!** increases the count by one and displays it next to Counter.
- **Reset** resets the count to zero.
- **Space** also increases the count by one.

## Changes

I implemented counter updates when Click Me! is pressed, added a Reset button to return the counter to zero, and added Space key support.

## Run locally

Start the development server with `deno task dev` and open the local address it prints.
